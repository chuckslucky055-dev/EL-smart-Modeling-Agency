# EL-smart Modeling Agency

Responsive modeling agency portfolio and enquiry website demo.

## Features
- Agency introduction and services
- Model portfolio showcase (demo placeholders)
- Casting and booking enquiry links via WhatsApp
- Contact section and mobile-responsive styling

## Run locally
```bash
npm install
npm run dev
```

Live demo: https://el-smart-modeling-agency-9lvyc7.v2.appdeploy.ai/

Portfolio imagery and sample content are placeholders for this demo and should be replaced with approved agency assets before production use.
